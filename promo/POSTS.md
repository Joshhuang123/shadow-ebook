## 二、简介正文

### 小红书

```
孩子的英语录音,不上传云端。

这是我给自己孩子做的英语阅读器,叫影子电子书。家里一台电脑就够,
平板打开浏览器就能用。

读起来是纸的排版,不是网页。点单词查释义,查过的词自动进生词本。
「上一句/下一句」一句一句地走,走到底自动翻页 —— 家长要能把孩子
停在某一句上跟读,翻页一次跳 7 句,落不到点上。

跟读这块花的时间最多。别的软件只说你这个词读错了,它直接说:
「『walking』里的 /AO/ 还不稳,长 o 像 go」。词有两万个,音只有几十个,
音才是能练的东西。

知识图谱把教材、考纲和掌握度画在一张图上,这一章要会什么、先要会什么,
一眼看到。家长页是诊断不是报表:哪个音还不稳、哪个知识点没学会,直接列出来。

完全离线可用,中文界面,MIT 开源。
https://github.com/Joshhuang123/shadow-ebook

(视频由 TTS 配音 + 程序渲染生成,画面全部是软件真实运行截图)
```

## 三、创作者首评(发布后立刻发)

> 实测:知识类内容最常见的死法是**观众不知道该说什么**。
> 自己先发一条「补充信息 + 一个具体问题」,等于替观众把第一句话写好。

```
补充两点视频里没说的:

① 跟读那句「/AO/ 还不稳」不是修辞。词库 18254 个词,但音素只有 41 个
   (CMUdict 的 ARPAbet,含 2 个伪符号)—— 音才是能练的单位。

② 转写跑在本机(faster-whisper,不用装 torch,省 2.3GB 磁盘),
   孩子的录音不出这台机器。唯一的例外是语法出题会调一次 LLM,
   发的是语法点,不是孩子的原文。

问题:你家孩子读英文最容易卡在哪个音?
```

## 六、互动层(已内嵌在成片里)

| 位置 | 做什么 |
|---|---|
| 前 3 秒 | 钩子:**「孩子的英语录音,不上传云端。」** —— 反常识 + 后果型。**不塞关注引导** |
| 正片中段 | 不喊点赞收藏关注三连 |
| 片尾 | 预告一次互动题:「你更想要哪一种,整屏读,还是一句一句跟读?评论区说说。」 |
| 收藏钩子 | 片尾/简介给「可保存的那一屏」:12 个最容易读错的音的嘴型表 |

内容里留了一个**可以被反驳的口子**:「跟读就该说这个词错了,说音素有什么意义?」
——这一条是能引出真讨论的,纯知识陈述句引不出评论。

## 七、发布节奏

- **投放时段**:早 6 点 / 晚 22 点(智海论衡实测这两个档小红书观看量最高)
- **一稿多投**:小红书、抖音、视频号各改一次头(标题 + 封面 + 前 3 秒 + 标签)
- **发布后 48 小时**:逐条回评论,每条都带增量信息;第 3 天后别再投入
- **第 7 天**:记一次数据台账(收藏率、有效评论占比、搜索来源占比分开记,
  不要合并成「互动率」——合并了就看不出哪条规则有用)
