书导不进来?多半是被加密了

从图书馆借的书(OverDrive / Libby)、Kindle 买的大多带 DRM 加密: 文件后缀是 .epub、结构也完全正常,但正文是加密的, 任何自建阅读器都读不了 —— 这不是操作问题,换台电脑也一样。

Standard Ebooks
公版名著,排版最干净,本来就是给电子墨水做的。全部无 DRM。
standardebooks.org
Project Gutenberg
六万多本公版书,免费的,格式干净。儿童文学和经典都有。
gutenberg.org
Internet Archive
扫描件存档,也有部分可下载的 EPUB。扫描版要先 OCR 才能读。
archive.org
Kindle 买的小说
2026 年起,亚马逊支持下载部分 Kindle 书的「无 DRM EPUB」;用「Send to Kindle」传 EPUB 也行。
amazon.com

同一本书如果在上面这些地方有公版版,导那个就行 —— 内容一样,但没有锁。

朗读声音

四种语音来源随便换：Mac 自带的系统语音（免费、离线、语速可调）、 微软 Edge TTS（要联网，音色多）、你自己的语音服务 （Piper / GPT-SoVITS / 任意 OpenAI 兼容接口），或者平板自己的声音。 密钥只存在这台服务器上，不会发给平板。

服务地址
到 /v1 这一层即可，程序自己拼 /audio/speech。本地服务填局域网地址，例如 http://192.168.1.10:8000/v1
API Key
本地服务一般留空。留空 = 不修改已保存的密钥。
模型名
OpenAI 官方是 tts-1；自建服务看它自己的文档
系统音色
Mac 自带音色名，例如 Samantha、Alex、Karen。
在「系统设置 → 辅助功能 → 朗读内容」里可以下载更自然的增强音色。
语速
词/分钟。刚开始学英语的孩子建议 140~160，标准是 175。
语速微调
在原速基础上加减，例如 -10% 慢一点、+10% 快一点。 刚开始学英语的孩子建议 -10%，跟读时更容易跟上。
音色
微软用 en-US-AriaNeural 这种名字；自建服务看它支持什么
