# 设计提示词 — 直接复制粘贴用

## 提示词 A:整体设计(五页一起)

```
帮我设计一个儿童英语阅读学习应用的前端界面。

【这是给谁用的】
一个 10 岁的孩子,每天用 iPad 打开,大概 20-30 分钟。
他的中文是母语,英语是正在学的,认字量有限,坐不太住。
界面文案是中文,书里的内容是英文。
除了孩子,家长会偶尔用手机看一眼学习进度。

【这是干什么的】
家里自用的局域网工具,平板和电脑连同一个 WiFi 就能用,不需要注册登录。
所以没有注册页、没有账号、没有社交、没有排行榜。

【有 5 个页面,请分别设计】

1. 阅读器 —— 最核心的页面
   一次显示 1-3 句英文大字号,句子之间留白宽松。
   点任意一个单词,弹出释义卡(音标 + 中文意思 + 例句),
   这个弹窗是最高频交互,设计上要最不打断阅读。
   顶部是书架和章节切换,底部是字号调节和朗读按钮。
   重点:孩子要能一眼看到"现在读到哪了"。

2. 跟读 —— 听录音对比
   先听原音,然后按录音,录完把原音和孩子的录音画成波形叠在一起对比。
   下面给出 AI 反馈,指出哪个词读得不好。
   重点:录音按钮是全页主角,要大到不可能按错。
   波形对比要让孩子一眼看懂"哪里不一样",不要抽象。

3. 语法练习 —— 做题
   分区:英语考试语法(KET / PET)、小学英语教材。
   点一个语法点就开始出题,大按钮选项,点一下立刻判对错。
   部分题目是 AI 现场生成的。
   重点:一屏一题,不要让人分心。

4. 学习统计 —— 给孩子的成就感
   主角是一个大数字:连续学习天数。
   下面是最近 7 天的学习时长柱状图,一个词汇量测试入口。
   重点:要让孩子觉得"我坚持下来了",而不是数据报表的冷冰冰。

5. 家长中心 —— 和孩子页面明显不同
   需要 4 位数字 PIN 进入(锁的隐喻)。
   今日学习时长、学习的单词数是两个主指标,
   下面是词汇/语法/跟读三项掌握进度,还有改 PIN 和重置数据。
   重点:家长页要更克制、信息密度更高,一眼能看出"这不是给孩子玩的"。
   重置数据这种危险操作要放远,并且要二次确认。

【硬性要求,违反就是没做对】

- 所有能点的地方,最小 48×48 像素。这是 iPad 上孩子手指的可靠命中范围,不能妥协。
- 每个页面只能有一个视觉焦点,孩子的眼睛第一眼只能落在一处。
  其余元素都退到次要层级。
- 英文正文至少 24px,中文解释至少 16px。孩子是刚学英语的,字大了才敢读。
- 按钮分三档:48px(导航等次要操作)/ 60px(答题选项、确认这类主动作)/
  72px(播放录音按钮,圆形)。
- 主要按 iPad 横屏设计(1024-1366px 宽),兼顾手机。
- 支持深色模式,而且深色要重新配色,不是把浅色反过来 ——
  背景用带暖调的深黑,文字用米白,不要纯黑纯白,长时间看不刺眼。

【视觉调性】
温暖、安静、像在翻一本书,不像在用一个 App。
米白和暖棕的底子,低饱和,不闪不弹不发光。
不要科技感网格、不要蓝紫渐变、不要发光特效 —— 装饰必须有用处,
这个孩子每天要看 20 分钟,任何抢注意力的东西都是负担。
配色你自己定,只要满足"暖、低饱和、长时间看不累"就行。

【输出】
先说你打算怎么解决"一个不太坐得住的孩子怎么走完一轮学习",
再给每个页面的界面方案。
每个页面说明:主要元素怎么排布、焦点在哪、孩子第一眼看到什么。
最后列出你做的取舍,以及你不确定、需要问用户的地方。
```

## 提示词 B:单页迭代(改某一页时用)

```
我在改一个儿童英语阅读应用的「页面名」页面。

使用者是 10 岁孩子,在 iPad 上用,界面中文、内容英文。
当前这页是给「一句话说明这页在干什么」。

我看到现在的样子是「贴当前的截图,或者描述现状」。
我不满意的是「具体哪里不对劲」。

我要的是「你想要什么效果」。
注意:所有可点区域至少 48×48,每页只能有一个视觉焦点,
英文正文至少 24px。不要蓝紫渐变和发光特效,整体要暖、安静、耐看。

请给我这一页的新方案,并说明相比现在的版本改了什么、为什么。
```

## 用法提示

- 提示词 A 一次出五页,适合先看整体方向。
- 觉得哪页方向不对,单独用提示词 B 迭代,别让 AI 一次改五页。
- **别把 `docs/DESIGN.md` 一起喂进去**。那是给开发者看的实现约束
  (token 名、CSS 变量、迁移路径),对生图/设计工具是噪音,反而会束缚它。
- 设计稿出来后重点检查两件事:触控目标真的够大吗?每页焦点真的只有一个吗?

## 提示词 C:书架页第二轮(改上面三个问题 + 补三处)

```
我已经看过第一版书架页设计了,整体方向我认可,现在只需要改几处,
请基于第一版修改,不要推翻重画。

【第一版做对的地方,保持不变】
- 空状态那个"趴着看书的孩子"插画 + "开始你的第一本书吧!" 很好,保留
- 导入流程的三段式(选文件 → 导入中 → 解析完成)保留
- 无封面用插画占位、跟有封面的卡片规格统一,这个思路保留
- 继续读区压过网格的层级关系保留
- 奶油米白底 + 暖沙色强调 + 暖黑文字,配色方向保留

【要改的三个问题】

1. 同一本书在一屏出现了两次
   继续读区是 The Little Prince,下面的网格第一张卡又是同一本,
   封面和"第 5 章 / 共 12 章"完全一样,孩子会困惑是两本还是一本。
   请改成:正在读的那本不重复出现在网格里,或者它在网格里时明确标注
   "正在读"并把封面做成更弱化的处理(比如降低对比度)。
   我倾向前者 —— 直接不重复,网格只放还没在读的书。

2. 窄屏网格列数太多
   第一版手机宽度下网格还是 4 列,每张卡实际只有 60px 宽,孩子点不准。
   请改成:平板横屏 4 列,手机竖屏最多 2 列。
   并且请把手机 2 列的样子画出来,我要确认。

3. 空状态文案有个错
   现在写的是"选择下方的「导入书籍」添加",但按钮就在那句话的正下方,
   不在"下方",而且"选择"和按钮的动作也对不上。请改成能直接指向按钮的说法。

【要补的三处】

4. 排序规则
   不要按添加时间排。请改成:
   正在读的 → 最近读过的 → 剩下的(按添加时间)
   理由是孩子回来的时候他记得的是"上次读那个",不是"上个月加的那个"。

5. 章节要能看见
   现在卡片上只有"第几章",孩子不知道书里面有什么。
   请设计一个让孩子能看到章节列表的方式(点击、悬停、长按、或者直接展开,
   你选一个更符合平板操作的),要能看出每章的标题和句子数,
   以及哪几章已经读过。

6. 暗色模式
   暗色不是把浅色反过来,是要重新配色:
   - 背景用带暖调的深色(接近 #1A1714 这种,不要纯黑)
   - 文字用米白(接近 #EDE6DA,不要纯白,长时间看不刺眼)
   - 强调色要变亮一档才能在深底上保持识别度
   - 封面图不要反色,反色会让人物失真
   - 插画和占位封面在暗色下也要能看,不要糊成一片
   请至少给"有书状态"和"空状态"各出一张暗色稿。

【硬性要求不变】
所有可点区域最小 48×48;每屏只能有一个视觉焦点;
主要按 iPad 横屏设计,兼顾手机窄屏。
